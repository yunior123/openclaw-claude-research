# openclaw-claude-research 🦞

> Studying OpenClaw (300k+ GitHub stars, #1 all-time) and its ecosystem to extract the best patterns for Claude Code AI-powered workflows.

## Goal

OpenClaw is the fastest-growing open-source project in GitHub history — overtaking React and Linux in under 60 days. This repo documents:

1. What makes OpenClaw's architecture special
2. Its tech stack under the hood
3. Top forks and derivatives (NanoClaw, ZeroClaw, ClawHub, Moltworker, etc.)
4. Which features map directly to Claude Code superpowers
