|---------|----------|----------------|
| **ZeroClaw** | Go | Minimal footprint, no Node.js dependency |
| **PicoClaw** | Rust | Extreme performance, sub-10ms latency |
| **IronClaw** | Rust | Security-hardened, air-gapped capable |
| **Moltis** | Python | ML-friendly, native HuggingFace integration |
| **NanoClaw** | TypeScript | Stripped-down, single-file deployable |

## Key Lessons from Derivatives

1. **Go/Rust rewrites** validate the Node.js version's architecture — same patterns, better perf
2. **Moltworker** (Cloudflare) shows the gateway can be serverless — stateless routing
3. **MemoryX** adds vector search on top of Markdown memory for semantic retrieval
4. **DevClaw** is the closest to Claude Code's use case — worth deep-diving
5. Skill marketplace pattern (ClawHub) is universally copied — it's the killer feature
